# 数独 · Sudoku

侧边栏底部的小图标，点一下弹出一个**可拖动、等比缩放**的数独窗口。题目完全在本地生成，不调用模型，玩多久都不消耗 token。

## 界面

- 全部颜色使用 Harness 主题 token（`--dsw-alias-*`），亮色/暗色主题自动跟随，不再是一块突兀的独立配色。
- 标题、印章、解答标题使用品牌字体（含思源宋体/宋体回退），正文使用 Harness 文本字体。
- 窗口锁定 0.69 的宽高比：拖动右下角手柄只会等比缩放，不会拉出一条横向空白。
- 快捷键直接标在功能键下方，没有单独的提示行。

## 难度

三档都高于常见小游戏的「简单/中等」：

| 档位 | 线索 | 判定 | 平均生成 |
| --- | --- | --- | --- |
| 困难 | ≤32 | 试错分支 ≥3 | 0.1–0.5s |
| 专家 | ≤28 | 试错分支 ≥8 | 0.5–1.5s |
| 大师 | ≤26 | 试错分支 ≥14，常需多步回溯 | 0.3–2.5s |

「试错步数」是本地求解器只用唯一候选/隐藏唯一推不动时被迫分支的次数；标题栏会显示当前题目的实际值。

## 功能

- 换一题 / 重来 / 三档难度即时切换
- 计时、暂停（暂停时棋盘模糊）
- 数字键或数字盘填写，方向键移动，鼠标点选
- 笔记（铅笔候选）与自动候选显示
- 撤销 / 重做 / 提示（填一格并计数）/ 检查（错误标红）
- 冲突、同数字、行列宫高亮
- 完成判定与按难度的最佳用时
- **完整解答**：逐步骤回放整道题，显示每一步使用的技巧（唯一候选、隐藏唯一、数对、区块指向、行列区块、X-Wing、试探）、位置、填入的数字和文字说明；大师题会明确标注「试探」步骤
- 快捷键：`1–9` 填写，`⌫` 擦除，方向键移动，`N` 笔记，`C` 候选，`U` 撤销，`Y` 重做，`H` 提示，`K` 检查，`E` 完整解答，`Esc` 关闭/退出回放

## 实现

- 生成：随机回溯填满终盘 → 180° 对称挖空并逐次校验唯一解（解数 ≥2 回填）→ 用「唯一候选/隐藏唯一」求解器统计试错分支数，按档位阈值接受，超时取当前最优；分支搜索带节点上限，避免病态盘面卡住。
- 完整解答：记录每一步的盘面快照与技巧说明；常规技巧无法推进时，从已知唯一解取候选试填，并标注为试探步骤。
- Host 半边不注册任何服务、路由或模型工具。

## 存储

`localStorage`：`sudoku.game.v1`（当前局）、`sudoku.best.v1`（最佳用时）、`sudoku.ui.v1`（窗口位置与宽度，高度按比例推导）。

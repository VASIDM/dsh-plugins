# 纸墨 · 设计

`@local/paper-ink-design` · v1.0.0 · Web 界面

方角、平影、细滚动条、朱砂引线与标题墨线。

## 安装

```sh
dsh plugin --profile <profile> add "dsh-plugins/plugins/paper-ink-design"
```

## 源码

本目录为包根，清单见 `package.json`。

## 入口

- Web：`client.js`。
- Host：`index.js`。
- 组合：`cordis.patch.yml`。
- 行：`paper-ink-design`。

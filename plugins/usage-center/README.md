# 用量与额度（Usage Center）

DeepSeek Harness 侧边栏插件：在侧边栏打开一个与 DeepSeek 开放平台口径一致的用量面板。

## 功能

- **账户余额**：优先读取当前登录的 DeepSeek 账户余额；未登录时回退到 `DEEPSEEK_API_KEY` 的 `/user/balance`。
- **累计消费**：直接读取开放平台 `get_user_summary` 的 `total_costs`，与平台账单一致。
- **本期消费 / Token**：今日 / 近 7 天 / 近 30 天，直接读取平台 `usage/by_api_key/amount` 和 `usage/by_api_key/cost`。
- **柱状趋势图**：鼠标悬停每根柱子，同时显示该时间桶的 Token 消耗、实际金额和请求数。
- **Token 明细**：输入、输出、缓存读取、缓存写入、缓存命中率、请求数、会话数。
- **模型明细**：按模型拆分 Token、请求数、实际消费和占比。
- **任务消耗排行**：按会话/任务列出 Token、金额、请求数，可按 Token 或金额排名；金额按本地 Token 分布分摊平台实际消费。
- **快捷跳转**：直接打开开放平台的用量页和充值页。
- **自动刷新**：面板打开时每 45 秒刷新一次，也可手动刷新。
- **视觉**：参考本机「太初」插件，朱砂、墨黑、宣纸白，发丝线、纸纹、宋体标题与朱砂“量”字印章。

## 数据口径

- 余额、累计消费、本期消费和 Token 优先使用开放平台真实数据，浏览器不接触 API Key 或账户令牌。
- 平台接口不可用时，才退回本地会话日志 + 公开价目表估算，并在界面标注“本地估算”。
- 本地兜底金额按 2026-08-17 起的北京时间峰谷价目表计算（工作日高峰，周末/法定节假日空闲），仅作参考。

## 开发文档

从零开发这个插件的完整教程见 [TUTORIAL.md](TUTORIAL.md)，包含 Host/Client 分层、槽位选择、平台用量接口、`total_costs`、小时/日桶合并、柱状图 tooltip、安装验证和常见坑。

## 文件

- `index.js` — Host 半边：账户余额、平台用量、累计消费、本地兜底、只读汇总路由。
- `client.js` — Web 客户端：侧边栏入口、主面板 UI、柱状图、环图、模型表。
- `cordis.patch.yml` — 安装到 profile 的 bundle patch。
- `locale/{zh,en}.json` — 插件管理器的标题和描述。

# 纸墨 · 布局

`@local/paper-ink-layout` · v1.0.0 · Web 界面

版心收窄到 720px，对话行距放宽到 10px。

## 安装

```sh
dsh plugin --profile <profile> add "dsh-plugins/plugins/paper-ink-layout"
```

## 源码

本目录为包根，清单见 `package.json`。

## 入口

- Web：`client.js`。
- Host：`index.js`。
- 组合：`cordis.patch.yml`。
- 行：`paper-ink-layout`。

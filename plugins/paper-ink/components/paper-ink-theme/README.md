# 纸墨 · Paper & Ink

把 DeepSeek Harness 整个界面换成与《太初》开机页（`dsh-scifi-boot`）和「用量与额度」面板（`usage-center`）同一套的**纸墨朱印**。

**一个插件，四个组件**。插件列表里只有一张「纸墨」卡片（`@local/paper-ink`）；卡片里列出四个独立组件（配色 / 字体 / 布局 / 设计），每个组件单独一行、单独启停：

| 组件 | 改什么 | 实现 |
| --- | --- | --- |
| 配色 | 纸面、抬升面、墨字、朱砂强调、状态色、代码块、菜单、侧栏、气泡、滚动条、渐变（122 个令牌） | `ctx.theme.overrideTokens()`，浅/深两套值 |
| 字体 | 正文宋体（Songti/Noto Serif/SimSun），代码等宽，品牌字衬线 | 覆盖 `--dsh-font-family-*-default`、`--dsw-font-family-brand` |
| 布局 | 版心 720px，对话行距 10px | 覆盖 `--dsh-chat-user-width`、`--dsh-chat-flow-gap` |
| 设计 | 方角（2–10px）、平影、6px 细滚动条、朱砂引线引用、标题墨线 | 圆角/阴影令牌 + 会话流内的 CSS |

每个组件是一个独立的插件行：关掉哪一行，哪一层的令牌覆盖或样式就撤下；整张「纸墨」卡片停用则四层一起撤下。四个组件包已安装为 profile 依赖但不再是独立 bundle，所以不会在插件页各占一张卡片。

## 版框（已移除）

背景层曾做过窗口四周的双线版框，实际显示时绕出一圈与标题栏、侧栏、面板都不重合的小方框，不协调，已整条删除；背景现在只由「配色」的纸面底色负责，没有任何覆盖层。

## 字体组的边界

字体组件改的是**默认字族**。如果你在 **设置 → 通用 → 正文字体** 里填了自定义字体，那份设置优先。布局组件与宿主列宽拖拽共用 `--dsh-chat-user-width`：拖过对话列的话，拖动值优先。

## 改名

由 `@local/plugin-names` 提供：**设置 → 插件 → 「插件改名」**，点一下名字就能像改一段话那样直接编辑，失焦保存；写回本地插件包的 `locale/*.json`，刷新页面后插件列表显示新名字。内置插件在 asar 里只读，不列出。

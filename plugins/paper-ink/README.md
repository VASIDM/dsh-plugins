# 纸墨

`@local/paper-ink` · v1.0.0 · Host 插件

温纸作底、墨色作字、朱砂作印。包含配色、字体、布局、设计四个独立组件。

## 安装

```sh
dsh plugin --profile <profile> add "dsh-plugins/plugins/paper-ink"
```

## 源码

本目录为包根，清单见 `package.json`。

## 入口

- Host：`index.js`。
- 组合：`cordis.patch.yml`。
- 行：`paper-ink-palette`、`paper-ink-type`、`paper-ink-layout`、`paper-ink-design`。

# L — 长期偏好

L 是一个独立的侧边栏插件：从对话里辨认**跨任务的长期偏好**，作为每个任务的 standing requirements 注入系统提示，并在面板里查看、编辑、启停。

## 现在的判断逻辑

不是“命中关键词就记”。一条用户消息会先被拆句，再判断它是不是长期规则：

| 信号 | 行为 |
|---|---|
| `以后 / 每次 / 默认 / 始终 / 一律 / from now on` + 规则形状 | 高置信度，自动收录 |
| `我喜欢 / 我习惯 / 我偏向 / 我更愿意` | 高置信度，自动收录 |
| `请记住 / 记得 / 务必` | 显式记忆请求，自动收录（内容像一次动作时改为待确认） |
| 单独的 `不要 / 改用 / 应该 / 建议` | **不自动收录**，进入「待确认」 |
| `这次 / 现在 / 这个 / 刚才` 等一次性限定 | 降低置信度，进入「待确认」或直接丢弃 |
| 任务请求、问题、代码/URL、寒暄、语言设置 | 丢弃 |
| `#habit ...` | 显式标记，直接收录 |

还会做：

- 从带前置语境的句子里截取真正的规则（例：“这个项目先这样，以后都用 TypeScript” → “都用 TypeScript”）
- 用字符 bigram 相似度去重，避免近义重复
- 自动收录的条目带 confidence；低于 0.8 的在面板里标注
- 类似“我总是忘记保存”这种叙述句不会因为“总是”被误收
- 待确认区最多 20 条，接受后才进入系统提示，忽略不留记录

## 面板

- 顶部：L 印章、标题与采集/注入开关
- 四个指标：生效中、待确认、已学习会话、分析消息
- **待确认**：显示置信度、判定理由，可“收录”或“忽略”
- **已生效**：按安全边界 / 工作方式 / 审美与语气 / 输出格式 / 环境与工具 / 内容约定分组
- 每条习惯：类别、来源、强度、出现次数；双击正文可直接改
- **已停用**与**手动登记**折叠在下方
- 视觉：纸面、墨色、朱砂印；不依赖额外样式包

## 数据与工具

- 新存储：`~/.dsh/cache/l/habits.json`
- 兼容旧存储：`~/.dsh/cache/azl-habits/habits.json`（首次加载会迁移）
- 模型工具：`habit_list` / `habit_remember` / `habit_forget`
- API：`GET /api/l/state`、`POST /api/l/{add,update,delete,toggle,relearn,pending-accept,pending-reject}`

原名 `@local/azl-habits`；碧蓝航线 L2D 部分已移除。

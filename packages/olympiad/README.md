# Olympiad · IMO-level problems

侧边栏底部的「Olympiad」图标，点一下弹出一张纸墨风格的数学题卡片；题目与详细解答全部在本地，不消耗 token。

## 收录

9 道 IMO 级别题目，覆盖数论、代数、组合：

| 来源 | 类别 | 难度 |
| --- | --- | --- |
| IMO 1988 P6 | 数论（韦达跳跃） | ★★★★★ |
| IMO 1994 P1 | 数论（2 的幂整除） | ★★★ |
| IMO 2005 P4 | 数论（原根/费马） | ★★★ |
| IMO 2013 P1 | 数论（中国剩余定理） | ★★ |
| IMO 2014 P1 | 代数（数列不等式） | ★★★★ |
| IMO 2000 P2 | 代数（abc=1 不等式） | ★★★★ |
| IMO 2001 P2 | 代数（根式不等式） | ★★★★★ |
| IMO 2019 P1 | 代数（函数方程） | ★★★★ |
| IMO 1998 P2 | 组合（双重计数） | ★★★ |

## 功能

- 打开即随机一题；`Next` 换题（不连续重复当前题）
- 分类筛选：全部 / 数论 / 代数 / 组合
- 题目区显示来源、类别、难度圆点
- **Hint** 显示提示；**Detailed solution** 显示逐步详细解答（默认隐藏，避免剧透）
- 快捷键：`N` 换题、`H` 提示、`S` 解答、`Esc` 关闭
- 纸墨 + 朱红主题，亮/暗自动跟随 Harness；窗口 0.68 宽高比等比缩放
- 题目与解答为中文；界面标识为英文

## 数据

- `problems.json` 为题库；`build.mjs` 注入 `template.js` 生成 `client.js`。
- 题目来源为公开的 IMO 赛题；解答为本插件自撰的逐步证明。

## 存储

`localStorage`：`olympiad.ui.v1`（窗口位置与宽度）。

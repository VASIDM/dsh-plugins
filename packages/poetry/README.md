# 诗笺 · Poetry

侧边栏底部的「诗笺」图标，点一下弹出一张可拖动、等比缩放的诗词卡片。每次打开随机读一首古代诗词曲，全部内容在本地，不调用模型，不消耗 token。

## 收录

- **3291 篇**：诗 1725、词 1042、曲 524。
- 其中 **33 篇“精注”**（唐诗 19、宋词 10、元曲 4）：原文、注释、白话翻译、赏析、作者生平、时代背景齐全。
- 其余为**原典**：原文、作者、朝代、体裁；注释栏显示“精注待补”，并提供「读一篇精注」一键跳到精注篇目。
- 来源：chinese-poetry 开放数据集（MIT）中的《唐诗三百首》《宋词三百首》《诗经》《楚辞》《水墨唐诗》《纳兰词》《花间集》《元曲》《全唐诗》名家选；繁体原文统一转为简体。
- 随机打开时约 55% 概率落在精注篇目；切到「诗 / 词 / 曲」或「精注」筛选可自由浏览全部原典。

## 注解

- 精注篇目的原文（含标题）中出现的注释词会加**虚线重点 + 朱红序号上标**，编号与下方注释一一对应。
- 点击原文中的序号，自动切到「注释」栏并滚动到对应条目、高亮显示。
- 注释条目使用圆形朱红序号 + 词条 + 解释；未在原文出现的词条（如只出现在题目中的地名）会标在标题上。

## 功能

- 打开即随机一首；「换一首」再随机（不会连续重复当前这首）
- 体裁筛选：全部 / 精注 / 诗 / 词 / 曲
- 五个栏目切换：注释、白话、赏析、作者、背景
- 篇目标记「精注 / 原典」；原典篇目的作者栏会复用同名作者的生平（如有）
- 字号调节（A− / A+，0.9–1.2 倍），偏好会记住
- 收藏（☆ / ★），收藏列表存在本地
- 一键复制原文
- 暗色/亮色主题自动跟随 Harness：宣纸朱印 / 夜墨朱
- 窗口锁定 0.66 宽高比，右下角拖动等比缩放；位置与宽度会记住
- 快捷键：`R` 换一首，`F` 收藏，`1–5` 切栏，`+/-` 字号，`Esc` 关闭

## 数据

- 精注内容在 `data-shi.json`、`data-ci.json`、`data-qu.json`、`data-extra.json`。
- 原典语料：`tools/build-corpus.mjs` 读取 `raw/` 下的开放数据集（chinese-poetry，MIT），用 OpenCC 统一为简体并去重，生成 `corpus.json`（3291 篇，含 33 篇精注）。
- `build.mjs` 把 `corpus.json` + 作者小传注入 `template.js`，生成 `client.js`；运行时不需要网络。
- 诗词原文属公有领域；精注的注释、白话翻译、赏析文字为本插件自撰。
- 作者生平和时代背景为简明介绍，生卒年有争议处采用通行说法。

## 存储

`localStorage`：`poetry.ui.v1`（窗口位置与宽度）、`poetry.fav.v1`（收藏）、`poetry.scale.v1`（字号）。
